The Gap

Ground stations are accurate. They're also nowhere near enough.

CPCB monitoring gives precise PM2.5, PM10, and NO₂ readings — but only where a physical station exists, almost always in cities. Rural and agricultural regions, including the areas that produce some of the season's worst pollution events, have little to no ground coverage.

Satellites don't have that gap. Sentinel-5P passes over every region daily, sensor or no sensor, measuring atmospheric formaldehyde — a marker tied to biomass burning and industrial VOC emissions.

The Pipeline

From orbit to hotspot, five steps.

Every region runs the same deterministic sequence, so results stay comparable across Delhi-NCR, Punjab, and Kanpur.

01 Retrieve Pull tropospheric HCHO column density from the Sentinel-5P TROPOMI offline product for each region's bounding box.
02 Filter Drop low-quality retrievals — cloud fraction above 0.3, QA value below the recommended threshold.
03 Baseline Build each grid cell's historical normal from prior observations at the same time of year.
04 Detect Score how far today's reading sits from that cell's own baseline — not a fixed threshold, a relative anomaly.
05 Cluster Group neighboring high-anomaly cells into a single named hotspot, sized by severity.
